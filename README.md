# «Посмотри в окно»

Веб-сайт с видеороликами о самых красивых и интересных городах мира. Это учебный проект, созданный для демонстрации навыков продвинутой верстки и стилизации интерфейсов.

## 📝 Описание проекта
Основная идея сайта — собрать в одном месте вдохновляющие видео о городах и представить их в удобном, визуально приятном формате. 

**В этой работе я впервые применил(а) продвинутые техники CSS:**
* **Псевдоклассы и псевдоэлементы** — для создания интерактивных кнопок, плавных эффектов при наведении и декоративных элементов оформления без изменения HTML-структуры.
* **Стилизация веб-форм** — стандартные поля ввода и кнопки были полностью переработаны под уникальный дизайн сайта с обработкой состояний фокуса (`:focus-visible`) и активности.
* **Сложные селекторы** — для точечного управления стилями элементов в зависимости от их расположения в коде.
* **Автоматическая проверка кода** — в проекте были настроены и использованы линтеры, которые помогают следить за качеством кода и избегать дублирования селекторов.

## 🛠 Технологии
* **HTML5** (включая семантические теги и тег `<video>` для интеграции медиаконтента).
* **CSS3** (активное использование псевдоклассов `:hover`, `:active`, `:focus`, псевдоэлементов `::before`/`::after` и кастомная стилизация форм).

## 💻 Системные требования
Для запуска и просмотра этого проекта **не требуются** мощный компьютер, базы данных или специальные серверные программы. Проект полностью статический.

**Минимальные требования:**
* **Операционная система:** Windows 7+, macOS 10.12+ или Linux.
* **Браузер:** Любой современный веб-браузер с поддержкой HTML5-видео и современных CSS-свойств (Google Chrome, Яндекс.Браузер, Mozilla Firefox, Safari, Microsoft Edge последних версий).
* **Для разработчиков:** Установленный Git (для клонирования) и любой редактор кода (например, Visual Studio Code), если вы хотите изучить исходный код.

## 🚀 Инструкция по запуску
Чтобы запустить проект локально на своем компьютере, выполните следующие шаги:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/yekaterinamyasnikova2007-a11y/posmotri-v-okno-fd.git
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd posmotri-v-okno-fd
   ```
3. Откройте файл `index.html` в любом современном браузере (Google Chrome, Firefox, Safari).
